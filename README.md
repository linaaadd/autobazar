# 🚗 AutoBazar NL — Telegram Bot

Telegram-бот для покупки и продажи автомобилей в Нидерландах.

**Бот:** [@autobazar_nl_bot](https://t.me/autobazar_nl_bot)  
**Канал:** [@autobazar_nederland](https://t.me/autobazar_nederland)

## Структура

```
autobazar/
├── bot.py
├── database.py
├── requirements.txt
├── railway.toml
└── webapp/index.html
```

## Деплой (Railway)

- Root Directory: `autobazar`
- Start: `python bot.py`

## Переменные окружения

```env
TELEGRAM_TOKEN=...
ANTHROPIC_API_KEY=...
```
